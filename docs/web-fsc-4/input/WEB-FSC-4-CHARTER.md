## How the proof could be faked (the gates are written against these)

- Counting index pages, breadcrumbs, the nav or the footer as contextual inbound links, which hands every page its minimum for free. Inbound means anchors inside `<main>` on distinct pages that are not index pages, excluding the breadcrumb.
- One related-links block pasted identically across a section. Each page's generated links come from its own edges, and the gate fails if any two pages carry an identical generated link set.
- A chrome script that only rewrites the pages it was tested on. `chrome.py --check` runs over every served page.
- A dash sweep that rewords. The fidelity check compares each swept page's word sequence, punctuation stripped, before and after: identical, or the page is listed with the ruling that also touched it (7 to 11).
- Pending markers on links whose page exists, to hide a typo or a broken path. `links.py --check` fails on any pending target that resolves.
- Moving every date to the deploy date to look fresh. The gate lists every page whose date moved, and the list must equal ruling 13's four.
